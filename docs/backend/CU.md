CASOS DE USO:
C01: Iniciar sesión - El usuario ingresa sus credenciales (email y contraseña) y el sistema verifica si son correctas. Si son correctas, el usuario es redirigido a la pantalla principal. Opcionalmente, el usuario puede iniciar sesión con Google.
C02: Registrar sesión - El usuario ingresa sus credenciales (Nombre, email y contraseña) y el sistema verifica si son correctas. Si son correctas, el usuario es redirigido a la pantalla principal. si son incorrectas, se enviará un mensaje de error indicando el error (usuario ya registrado o datos inválidos).
C03: Listar sesiones - El usuario puede listar todas las sesiones.
C04: Detallar sesión
C05: Actualizar sesión
C06: Eliminar sesión
